## 🚀 Featured Software Project

### 🔧 [AutoMitra — Vehicle Service Center Management System](https://github.com/AdigarlaRakesh-1/Automitra)
An open-source automotive workshop operations management web application localized in **Indian Rupees (₹ INR)**.

- **Authoritative Financial Calculations**: Server-authoritative bill generation from raw parts and technician labor hours with exact `Decimal('0.01')` precision.
- **Concurrency & Inventory Safety**: Atomic conditional stock deductions (`WHERE stock_quantity >= :qty`) preventing race conditions and negative inventory during peak bay activity.
- **Strict Data Preservation**: Enforced `ON DELETE RESTRICT` constraints preventing cascade deletion of historical invoices, payments, and service job logs.
- **Security & Quality**: 100% cryptographic CSRF verification across 18 forms, production error sanitization, and a **53-test automated regression suite** verified against live MySQL 8.0 service containers.
- **Release**: [AutoMitra v1.0.0 Release](https://github.com/AdigarlaRakesh-1/Automitra/releases/tag/v1.0.0)
